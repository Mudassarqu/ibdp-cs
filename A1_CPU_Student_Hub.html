Topic Explanation — CPU Components
A1.1.1 · SL 11 hours · HL 18 hours
🖥️ CPU Architecture Diagram
Core Diagram
ALU
Arithmetic Logic Unit
Performs ALL calculations and logical operations inside the CPU.
Arithmetic: addition, subtraction, multiplication, division
Logical: AND, OR, NOT, XOR, comparisons
Results stored in the Accumulator (AC)
CU
Control Unit
Coordinates ALL activity — the manager of the CPU.
Fetches instructions from memory
Decodes instructions in the IR
Sends control signals to all other components
REGISTERS — 5 Key Types
Ultra-Fast Storage Inside CPU
PC — holds address of NEXT instruction
IR — holds CURRENT instruction being decoded
MAR — holds the memory ADDRESS to access
MDR — holds DATA read from or written to memory
AC — stores result of last ALU operation
BUSES — 3 Types
Pathways Between Components
Address Bus — carries memory addresses (MAR→Memory) · UNIDIRECTIONAL →
Data Bus — carries actual data (MDR↔Memory) · BIDIRECTIONAL ↔
Control Bus — carries read/write/clock signals (CU→all) · BIDIRECTIONAL ↔
⚡ Processor Types
Single-Core Processor
One processing unit — executes one instruction stream at a time sequentially. Older computers used single-core CPUs.
Multi-Core Processor
Multiple independent cores on one chip (e.g. quad-core). Each core can execute its own thread simultaneously — true parallelism.
Co-Processors
Specialist chips that offload specific tasks from the main CPU — e.g. GPU (graphics/AI), FPU (floating point), NPU (neural networks).
GPU (A1.1.2)
Graphics Processing Unit — thousands of small cores for parallel computation. Used for gaming, AI training, video rendering, scientific simulation.
🔄 Fetch–Decode–Execute Cycle
Step 1
FETCH
1. PC → MAR (address)
2. MAR → RAM (request)
3. RAM → MDR (data)
4. MDR → IR (instruction)
5. PC increments (+1)
Step 2
DECODE
CU reads the IR
Identifies the operation
Identifies operands
Sends control signals
Prepares for execution
Step 3
EXECUTE
ALU performs operation
Result stored in AC
May write to memory
Cycle repeats
Billions of times/second

Specimen Paper Analysis
Official IB questions with mark-scheme answers and examiner tips
Q1(a) — HL Paper 1 Specimen · A1.1.1
[2 marks]
A team of programmers use PaaS via their laptops to develop a software application.
Outline the function of an accumulator.
📌 IB COMMAND TERM: "Outline" = give a brief account or summary. You need TWO distinct points for 2 marks.
Outline ≠ Define2 marks = 2 separate pointsEach point separated by semicolon (;)
✅ MARK SCHEME ANSWER
✓To store intermediate arithmetic and logic results / hold operand data; [1 mark]
✓…to reduce the number of memory accesses by holding intermediate results; [1 mark]
Also accepted: Acts as a temporary storage location; …which stores values and results from arithmetic and logical operations;
💡 EXAMINER TIP
Saying "the accumulator stores data" earns zero. You must say it stores results of arithmetic/logic operations. The second mark comes from explaining WHY — it reduces the need to access slower RAM. Always look for two linked ideas when a question is [2].
Practice Q — A1.1.1 Registers & FDE Cycle
[4 marks]
Explain how the Program Counter (PC) and Memory Address Register (MAR) interact during the fetch phase of the FDE cycle.
📌 IB COMMAND TERM: "Explain" = give a detailed account including reasons or causes. Link cause and effect.
PC = next addressMAR = address to access4 marks = 4 linked points
✅ MARK SCHEME ANSWER
✓The PC holds the address of the next instruction to be fetched from memory; [1]
✓This address is copied from the PC to the MAR; [1]
✓The MAR then sends this address along the address bus to RAM to request the instruction; [1]
✓The PC is incremented (+1) so it points to the next instruction for the following cycle; [1]
💡 EXAMINER TIP
For "explain" questions, always connect the WHAT to the WHY. Don't just say "PC goes to MAR" — explain that this is so the CPU knows which memory address to access. Use the term "address bus" to get full marks. Increment of PC is a very commonly missed mark point.
Q4(c) — HL Paper 1 Specimen · A1.1.2 GPU
[2 marks]
A hospital uses a deep learning convolutional neural network (CNN) to analyse chest X-rays.
Outline one reason a GPU is recommended when training a deep learning CNN model using a large dataset.
📌 KEY TERMS TO USE
Parallel processingMatrix operationsMany smaller coresTraining speed
✅ MARK SCHEME ANSWER
✓Deep learning involves many matrix operations (multiplications and convolutions); [1]
✓GPUs have many smaller cores designed for parallel operations, significantly speeding up training time; [1]
Also accepted: Large datasets increase computational demand; training on CPU alone would be too time-consuming / GPUs speed up training;
💡 EXAMINER TIP — The GPU Answer Formula
Always link TWO things: (1) what AI/ML needs — parallel matrix operations, and (2) what the GPU provides — thousands of smaller cores for parallel processing. Without the link you get only 1/2. The magic word for GPU questions is always "parallel".
