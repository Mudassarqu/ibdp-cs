How text is stored

Every character you type is held as a number, and that number is held as binary. ASCII uses one byte per character; Unicode extends the same idea to every writing system on Earth.

Why ASCII was designed this way

ASCII began as a 7-bit code in 1963, giving 27 = 128 characters. An 8-bit extension raised that to 28 = 256. Unicode (UTF-8) keeps those first 128 codes identical, so every ASCII file is already a valid UTF-8 file — then uses 2, 3 or 4 bytes for everything else. A lead byte starting 110 means two bytes, 1110 means three, 11110 means four, and every continuation byte starts 10.

File size

size = width (px) × height (px) × colour depth (bits per pixel)

Exam note: the raw calculation never matches the real file size. Headers and metadata — dimensions, colour depth, creation date, camera settings — are stored alongside the pixel data.

One pixel in 24-bit true colour

Three channels — red, green and blue — each stored in one byte, giving values 0–255. 224 = 16,777,216 colours.

Analogue to digital conversion

The blue curve is the continuous analogue sound wave. The dots are samples — amplitude measured at regular intervals. The orange staircase is what actually gets stored, after each sample is rounded to the nearest level its bit depth allows.

Analogue signal Sample points Stored digital signal

Sample rate

How many times per second the amplitude is measured, in hertz. More samples give a closer match to the original wave.

Bit depth

How precisely each individual sample is recorded. Levels = 2depth.

Storage required

Formula: sample rate × bit depth × channels × seconds = total bits. Compression: WAV and AIFF store this raw. MP3 is lossy — it permanently discards sound the ear is least likely to notice. FLAC is lossless — smaller, with nothing thrown away.

Video is a sequence of still frames

Each frame is stored exactly like an image. Played back fast enough — usually 24 to 60 frames per second — they create the illusion of motion, just like a flipbook.

Spatial compression — within one frame

Also called intraframe. Removes redundant detail inside a single frame — reducing colour depth or fine detail the eye will not miss. Works well where each frame carries a lot of changing detail.

Temporal compression — between frames

Also called interframe. Stores only what changed from the previous frame. In the strip above, that is roughly 3% of the pixels instead of all of them.

Two's complement — the standard for signed integers

To negate a number: invert every bit, then add 1 to the least significant bit. The most significant bit ends up acting as the sign — 0 positive, 1 negative — and unlike one's complement and sign-magnitude there is only one representation of zero.
