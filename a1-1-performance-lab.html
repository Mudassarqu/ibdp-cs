The two things that actually decide a hit rate.

A bigger cache holds more of the working set, so more requests are found before RAM.

How often the program reuses data it has just touched. A loop over a small array has high locality; jumping randomly through a huge data set has almost none.

Prefetching predicts what will be needed next and loads it into cache ahead of time, lifting the hit rate.

Controls

Two independent buses, two independent effects.

This sets the memory capacity of the system. It has nothing to do with how fast data moves.

This sets how much data moves at one time. Common widths are 8, 16, 32 and 64 bits.

The exam distinction: address bus width → how much memory you can reach. Data bus width → how fast you can move it. Students mix these up constantly.
